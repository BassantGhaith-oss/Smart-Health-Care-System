# Smart IoT Heart Monitoring & Healthcare System

This project is an IoT-based smart healthcare system designed to continuously monitor a person's heart rate using a wearable heart-rate sensor, similar to the sensor used in a smartwatch.

The sensor collects the user's heart-rate data and sends it to an IoT dashboard, where the user's heart rate can be monitored in real time and stored as historical data. The dashboard displays graphs such as **Heart Rate vs. Time** and allows the user or healthcare staff to track changes in the patient's condition.

The system can use additional information such as **age, gender, body temperature, and heart-rate patterns** to evaluate the user's condition. A Machine Learning model can analyze the collected data and classify the patient's condition into different levels, such as **Normal, Needs Attention, or Critical**.

Based on the detected condition, the system can automatically take appropriate actions. For example, it can notify the nursing staff when the patient needs attention or trigger an emergency alert when a critical condition is detected.

In critical cases, the system can also provide the user with basic recommendations, such as seeking medical assistance and identifying nearby healthcare facilities using a map.

Overall, the project combines **IoT, wearable sensors, embedded systems, cloud/dashboard monitoring, data analysis, and Machine Learning** to create a smart patient-monitoring and healthcare-assistance system.
