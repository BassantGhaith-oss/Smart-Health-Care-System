# PulseCare – Wearable Health Monitoring System ❤️

### From Breadboard to Wearable Health Monitoring
**Samsung Innovation Campus & Life Makers Graduation Project**

## 📌 Project Overview

PulseCare is an IoT-based healthcare monitoring system developed as our Samsung Innovation Campus graduation project.

After more than **200 hours of learning, development, and hands-on work over two and a half months**, our team built an integrated healthcare solution combining hardware, embedded systems, Machine Learning, and web technologies.

The system collects patients' vital signs through a wearable device, processes the readings, and uses a Machine Learning model to classify the patient's condition into three levels:

- 🟢 **Normal**
- 🟡 **Needs Attention**
- 🔴 **Critical**

## ❤️ System Architecture

The system consists of three main parts:

1. **Wearable Device:** Collects vital-sign readings through integrated sensors.
2. **Machine Learning Model:** Analyzes the collected readings and predicts the patient's condition.
3. **IoT Dashboard & Website:** Displays real-time health information and provides remote monitoring and alert management.

## 🔧 Hardware Components

The wearable device integrates the following components:

| Component | Purpose |
|---|---|
| Raspberry Pi | Main processing unit |
| MAX30102 | Heart-rate and SpO2 monitoring |
| Digital Temperature Sensor | Body temperature measurement |
| Accelerometer | Movement and activity monitoring |
| Touch Sensor | User interaction |
| TFT Display | Real-time readings and notifications |
| LED Indicators | Visual status indication |
| Buzzer | Audio alerts |

### PCB Design & Prototyping

Our hardware development progressed through several stages:

- Breadboard prototyping and circuit testing.
- Component connections and wiring design.
- PCB implementation.
- Hands-on soldering and hardware assembly.

## 📊 TFT Display Interface

The wearable device features a TFT display with three main pages:

- **Vitals:** Displays the measured vital signs.
- **Live Graph:** Visualizes incoming readings in real time.
- **Alerts:** Displays relevant alert messages.

## 🤖 Machine Learning

A Machine Learning model processes the collected health readings and classifies the patient's condition into three categories:

- Normal
- Needs Attention
- Critical

The model's prediction is integrated into the monitoring system to support timely notifications and healthcare follow-up.

## 🌐 IoT Dashboard & Website

The web platform provides remote health monitoring and access to patient information.

### Main Features

- Real-time vital-sign monitoring.
- Patient condition and Machine Learning predictions.
- Different access levels for patients, administrators, healthcare providers, and caregivers.
- Alerts for critical health conditions.
- Notifications to responsible persons, such as family members or healthcare providers.
- Access-request functionality that allows authorized users to request access to patient information.

The platform supports communication and coordination between patients, families, administrators, and healthcare providers.

## 🛠️ 3D Design & Wearable Enclosure

We designed and 3D-printed a rounded enclosure for the wearable device, bringing the electronic prototype closer to its intended wearable form.
